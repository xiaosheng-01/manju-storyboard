# 完整走通示例（祠堂对峙·一段原文的S0→S6全流程）

本示例为内置验证用例，演示从原文到交付物的完整管线。所有中间产物（拆点/准入/台词记录/俯视图/决策记录）都是 skill 的真实工作过程，最终交付物=分镜提示词块。

> **关于镜号**：本示例截取某集**第 6 镜**（前 5 镜已在前文完成），故镜号从"镜6"开始，非示例缺漏。S1 阶段出现的"镜6"是**预知编号**（拆点时已知本段将并为单镜），非时序倒置。
>
> **关于集长**：本段 12s 是**该集的一个节奏段**，不是"全集"。集长由整集内容排段累加得出（见 SKILL「留人节奏模型」），不设目标秒数。

## 输入原文（示例）

> 祠堂外雨声渐歇。萧远单膝跪在祠堂中央，左手撑刀，鲜血顺着刀脊缓缓滴落。他想起三日前沈璃叛出师门的那一幕，胸口像被死死堵住。沈璃持剑立在一步之外，手指缓缓收紧。"你早就知道，对不对。"萧远低声说。沈璃没有回答，只是缓缓后退了半步。供桌上的烛火轻轻一跳。

## S0a 建卡

```
角色卡：萧远——35岁，玄色劲装，束高马尾，左眉一道旧疤，腰挎长刀｜声线：低沉压抑｜关系：沈璃前同门，现敌对
        沈璃——28岁，素白襦裙，仅一支银簪，右手缠绷带，持剑｜声线：清冷｜关系：萧远前同门，三日前叛出师门
场景卡：场景1·祠堂内·雨夜｜光影基线：烛光唯一主光源，暖橙×冷青对撞，体积光浮尘｜物料：石材地面/木柱/供桌棉布帷帐｜空间结构：门[D]南墙，柱[P]东侧，供桌+烛火[E1]西侧
```

## S0b 拆点流

```
处理单元：示例段｜场景1·祠堂夜｜萧远、沈璃
①［场景卡旁路］祠堂外雨声渐息→场景卡音效层，不单独成点
②［剧情P1］萧远撑刀跪地、刀脊滴血→败者姿态确立（第2段）
③［情绪E1·压制］血缓缓滴落+屈辱姿态（第2段）
④［情绪E1·心理层］"想起三日前……胸口死死堵住"→双轨：可视化轨（视线低垂/呼吸迟滞）入情绪点；独白候选轨（第一视角自问）留S2判定（第3段）
⑤［剧情P2］沈璃持剑立于一步外、手指缓缓收紧→对峙确立（第4段）
⑥［情绪E2·升温］沈璃手指收紧+视线落点（第4段）
⑦［节拍B1·升级］台词D1：萧远→沈璃"你早就知道，对不对。"（第5段）
⑧［情绪E3·戒备］沈璃沉默、缓缓后退半步→无台词，动作即回应（第6段）
⑨［节拍B2·钩子候选］烛火轻跳→张力顶点留白（第7段）
```

## S1 准入结果

```
②③→拍｜刚需：剧情推进+情绪曲线｜理由：跪姿+滴血一秒立起力量关系，无前文观众也能入戏
④→拍（仅第一视角独白轨）｜刚需：揭露"为什么"｜旁白讲述部分弃用（第三视角，不录入）
⑤⑥→拍｜刚需：剧情推进+情绪升温｜理由：对峙双向确认，剑拔弩张
⑦→拍｜刚需：节拍升级+剧情信息（质问揭开"她知道布局"）
⑧→拍｜刚需：反应镜头+情绪曲线顶点｜置于D1后
⑨→拍｜刚需：章末钩子（烛火轻跳=不祥预兆+留白）｜与⑧重叠作背景层
镜级复核：全部存活点并入单镜（见S3），镜6过三问（开局立格局+心结+钩子收束）
```

## S2 台词车间

```
D1｜对白｜萧远→沈璃｜原文："你早就知道，对不对。"（净8字/1.78s）
  四问：意义=质问揭开信息（节拍升级引信）｜压缩=尝试"你早知道，对吧。"→伤笃定语气且省时<0.5s，否｜衔接=删则反应失去对象，必留｜动作化="她知道"不可见，不能代替
  定稿："你早就知道，对不对。"｜阴冷·慢·句尾停顿1s｜可视化：咬字很慢+每个字从紧咬的牙关里沉出来+视线钉死｜占位≈2.8s

OS1｜内心独白｜萧远（画面左载体，嘴不开合）｜原文心理："他想起三日前沈璃叛出师门的那一幕，胸口像被死死堵住"
  第一视角转译："她为什么要叛出师门？"
  四问：意义=揭露"为什么"（D1质问的动机来源）→有｜压缩=9字已是最短，删"为什么"变陈述丢疑问功能，否｜衔接=删不断但动机前史缺一角｜动作化=内心疑问拍不出，只能靠OS
  定稿："她为什么要叛出师门？"（OS·VO）｜沉·慢·句尾长停顿｜可视化：眉头微锁+视线缓缓落向地面+喉结滚动｜占位≈2.5s
```

```
  子2：⑤持剑+⑥手指收紧+视线 同步→max≈3.5s

```
