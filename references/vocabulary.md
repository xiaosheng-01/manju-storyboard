# 受控词表与禁词表

所有进入提示词的词语必须出自本表或本表的组合规则。表外词=先转译再入词。

## 一、景别（受控，5个）

| 景别 | 画面含义 | 用途 |
|---|---|---|
| 远景 | 人物极小，环境主导 | 格局/史诗感/场景建立 |
| 全景 | 人物全身+周边环境 | 空间关系/动作链/站位确立 |
| 中景 | 膝盖或腰以上 | 对峙/对话/双人关系 |
| 近景 | 胸部以上，面部清晰 | 情绪/台词/微表情 |
| 特写 | 局部占满画面（面部/物件） | 微表情顶点/关键细节/章末钩子 |

同一分镜内景别只能靠运镜渐变（缓推至近景、右摇成特写），禁跳切感。

## 二、运镜（受控，9个）

> ⚠️ **「后拉」与「横移」是两种不同运动，不可混用**：后拉=沿光轴后退，**景别变小**（近景→中景/全景）；横移=左右平移，**景别不变**，只改变取景范围。写"右拉至中景"是错的（横向移动不会改变景别），应写"缓缓后拉至中景"。

| 运镜 | 写法示例 | 必须答全 |
|---|---|---|
| 固定 | 镜头静止 | — |
| 推 | 镜头缓缓推近/推至萧远近景 | 跟随谁、怎么移、落到哪 |
| 拉（后拉） | 镜头缓缓后拉，沈璃入画/后拉至中景 | 跟随谁、怎么移、露出什么、**落定景别** |
| 摇 | 镜头缓缓右摇至沈璃特写 | 从哪摇到哪、落定景别 |
| 移（横移） | 镜头缓缓横移/跟随脚步移动 | 跟随谁、路径、落点；**景别不变，不得写成"横移至特写"** |
| 跟 | 镜头跟随她后退的动作 | 跟随对象、距离保持 |
| 升 | 镜头随抬头缓缓上移 | 跟随什么动作 |
| 降 | 镜头缓缓下移至握刀的手 | 跟随什么动作 |
| 环绕 | 镜头环绕二人缓缓推进 | 中心、方向、速度 |

运镜织入画面流，禁段首挂牌。禁无目的运镜。

## 三、渐变词与微动态词（受控）

- 程度渐变：缓缓/渐渐/逐渐/慢慢/微微/徐徐
- 状态持续：保持着/持续/始终/不住地
- 微动项（禁僵硬必留）：呼吸起伏/衣摆轻晃/发丝轻动/睫毛颤动/喉结滚动/浮尘缓动/火苗摇曳/绷带垂落轻摆
- 连接词（实时流）：同时/与此同时/紧接/随即/随后/话音未落/说时/此刻/说话间

## 四、情绪→语气标签映射（默认，可微调）

格式：（情绪·语速·停顿）

| 情绪 | 语速 | 停顿 |
|---|---|---|
| 暴怒 | 极快/快 | 零停顿 |
| 狂喜 | 快 | 短停顿 |
| 悲伤 | 慢 | 长停顿/句中停顿 |
| 阴冷 | 慢/低 | 句尾停顿 |
| 冷漠 | 慢/低 | 短停顿 |
| 犹豫 | 慢 | 多处停顿+微表情填充 |
| 温柔 | 慢 | 短停顿 |
| 戏谑 | 中/快 | 不规则停顿 |
| 隐忍 | 慢/低 | 句中压抑停顿 |
| 决绝 | 中/快 | 零停顿/句尾短停 |
| 沉冷 | 慢/低 | 句中长停顿 |

情绪词表封闭，新增需用户确认。

## 五、可视化三件套（语气必须肉身化）

每句定稿台词必配：
1. **咬字方式**：咬字很慢/从紧咬的牙关里沉出来/气声/一字一顿/脱口而出
2. **停顿时的面部微动作**：嘴角缓缓压平/视线仍钉在对方脸上/喉结缓缓滚动/眼睑压低
3. **视线是否保持**：钉死不移/缓缓垂下/移开半寸

## 七、音效声源词（受控）

- 人声：低沉缓慢的气声/压抑的呼吸声/脱口而出的喝声（带状态描述）
- 动作声：刀身轻响/剑刃轻吟/皮革握压的闷声/衣料摩擦/布料垂坠声/脚步声由重到轻
- 环境声：烛火噼啪/远处雷声/风穿回廊/雨声渐歇/浮尘不可闻但光影可见（光影写画面，不写声音）
- 禁：抽象声音描述（紧张的音效/压迫感音效）、音乐性描述（旋律/节奏/渐强/BGM）
- 句尾固定："；无BGM"

## 八、质感与物料词（I1 质感基线 / I2 物理真实，必达）

> **I1=质感基线**：风格行的构图定位 + 光影行的光源/色温/体积光/物料清单（本表前 6 行）。
> **I2=物理真实**：布料垂坠受力、重量感、惯性、碰撞反馈、粒子随光源动（本表"光"行后半 I2 部分 + SKILL S5「物理真实」条）。

- 皮肤：次表面散射的暖调/皮肤纹理/汗渍反光
- 织物：经纬纹理/布料垂坠受力/衣摆随动作轻晃/褶皱随呼吸起伏
- 皮革：油润光泽/握压变形
- 金属：冷硬反光/细微氧化痕/血顺着刀脊缓缓滑落
- 石材/木：粗糙压暗/纹理/反光柔和
- 光：主光源唯一/色温对撞/体积光/丁达尔/空气透视/浮尘缓动/烛火摇曳
- 构图：电影级构图/浅景深/前景虚实分层/景深压薄/背景缓缓虚化/面部占满画面

## 九、禁词表（提示词内零容忍，违者返工）

| 禁词类 | 具体词 | 替换方向 |
|---|---|---|
| 无过程跳变 | 突然/骤然/猛然/倏地/忽地/猛地/顿时 | 改为过程链：缓缓/渐渐+中间态（"烛火轻轻一跳"→"火苗缓缓拉长"） |
| 心理动词 | 他想/他觉得/他意识到/他回忆/心中暗想 | 转为可视化：视线低垂/眉头微锁/喉结滚动 |
| 画面行情绪命名 | 他很愤怒/悲伤/开心/紧张 | 情绪只进语气标签；画面行写物理形态 |
| 否定式 | 不要/不能/没有/避免 | 只写正向存在的东西。**本类只约束提示词正文**，规则文本、决策记录、元话语不受限（"禁淡入建景"这类规则表述合法） |
| 空泛炫技 | 史诗级/炸裂/极致震撼/超然/出神入化/电影大片既视感 | 写具体构图/质感词（见第八节） |
| 悬空引用 | 如上/如前所述/同左/"承接上镜"四字了事 | 承接块完整重述站位/姿态/镜头状态 |
| 第三视角旁白 | "三日前那一幕……"式讲述 | 转第一视角独白（"她为什么叛出师门？"）或弃用 |
