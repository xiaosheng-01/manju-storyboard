# 输出模板集

所有模板直接套用，×××处按规范填写。

## 一、分镜提示词块（核心交付物，一块=一次AI生成）

```
风格类型：×××（画风+构图定位，全剧恒定）
光影材质：×××（时段+地点+主光源+色温对撞+体积光+空气颗粒+真实物料清单，随场景变）
参考行：×××（本镜出场角色完整外观锚定，同剧恒定；多人用分号隔开）

0-××秒
画面：×××（实时流：起幅声明+运镜织入+站位锚定+动作链+台词内联+微表情+视线落点+微动项）
音效：×××（具体声源：人声+动作声+环境声）；无BGM
字幕：无

××-××秒
画面：×××
音效：×××
字幕：无
```

填写铁律：
- 首段必须声明起幅景别（无继承来源）；相邻段景别切换才声明"X景别起幅，"；同景别连续不声明
- 台词格式：角色（情绪·语速·停顿）："台词"；OS格式：角色（OS·VO，情绪·语速·停顿）："台词"
- 每句台词行文必含：说话人屏幕位置+视线落点
- 时间段总数1-4个，Σ=分镜总时长（10/11/12整秒），粒度0.5s
- 同场景非首镜：第一个时间段是0-0.5s承接块

## 二、0.5s承接块（同场景相邻分镜的首个子分镜）

```
0-0.5秒
画面：画面定格/微动于X景别；上镜落幅为：［人物A屏幕位置+朝向+姿态］；［人物B屏幕位置+朝向+姿态］；镜头状态［静止/微动项］
音效：×××（延续上镜的底噪）；无BGM
字幕：无
```

- 空镜分镜的承接=复述环境锚点（主体位置+光影状态），无人物站位
- 上镜动态收尾→用"微动"并延续该动作的缓慢态；静态收尾→用"定格"；都必须带持续微动项
- ⚠️ **禁止写"承接上镜"四个字了事**（禁词表"悬空引用"类）。上面模板的"上镜落幅为："后必须**逐项写全**站位/朝向/姿态/镜头状态，写成空壳即违规

## 三、ASCII俯视图（场景头，每场景一张，变更才重绘）

```
场景N·地点·时段｜俯视图（对应分镜X-Y，示意非测绘）
┌──────────────────────────────┐
│ ↑北                           │
│  ［环境锚点，如E1供桌·烛火］   │
│                              │
│  ●人物A［姿态］──朝向──►      │
│  ┄┄┄┄┄ 180°轴 ┄┄┄┄┄┄┄┄┄┄┄   │
│            ◄──朝向──●人物B［姿态］│
│                              │
│  ［D门/P柱等其他结构］         │
└──────────────────────────────┘
▷机位A1：世界方位·朝向·景别意图（时间段，如未入画注明）
      ⤏ A2：运镜节点（时间段）
      ⤏ A3：运镜节点（时间段）
屏幕映射（机位在X侧）：画面左=世界X｜画面右=世界Y
核对：人物世界方位→屏幕左右 ✓｜轴线未跨/经过渡镜 ✓
```

图例（全剧统一）：●=人物（名+姿态+朝向箭头）｜[E]=环境锚点｜[P]=柱/遮蔽｜[D]=门｜▷=机位｜⤏=机位/移动路径｜┄┄=180°轴。

规范：
- 上北下南左西右东；高度不表达，姿态用文字（跪/立/坐）
- 未入画人物也标位（世界真相与取景框无关）
- 屏幕映射必须由机位朝向推导后写明：机位朝北→画面左=西；朝南→画面左=东；朝东→画面左=北；朝西→画面左=南
- 关键距离文字标注（一步外）
- 中文宽度不追求格对齐，用关系示意+方位词定位

## 九、10秒炸弹表模板（S3.5产出，附交付）

> ⚠️ **本表用的是「节奏段」**（检查单位，约 10s），**不是子分镜**。子分镜的账在分镜提示词块里（每个「X-Y秒」就是一个子分镜，相加必须等于该镜时长）。

```
场景N｜节奏配段（节奏段按内容点走到功能完成划出，时长是累加结果，非目标值）：

| 节奏段序 | 时长区间 | 对应镜号 | 对应子分镜 | 功能标签 | 钩子内容（继续看的理由） |
|---|---|---|---|---|---|
| 1 | 0-13s | 镜6（子1~子3） | 0-3.5 / 3.5-7 / 7-13 | 炸弹+建戏 | ××× |
| 2 | 13-21s | 镜6子4～镜7子1 | 13-15.6 / 0-0.5 / 0.5-7.4 | 第一次升级 | ××× |
| 3 | …… | …… | …… | 加压 | ××× |

集尾落点：最后一镜=镜X，钩子类型=悬念/反转/情绪顶点
循环情况：□本集仅一整套序列　□第6段后循环N轮（N=__）
```

> 上表节奏段长 13s / 8s，**刻意不凑 10 的整倍数**——节奏段随内容走，可跨镜（第2段跨镜6～镜7）。
> **注意第2段跨了镜**，但这**不影响**镜6、镜7 各自内部 Σ子分镜 = 自己的整秒时长。

**填写规则**：
- 节奏段按原文内容点走到功能完成划出后**累加**得时长区间，**不得先定总时长再倒推分段**
- 功能标签只能取：炸弹/升级/加压/临界/爆发/钩子，**每段必须有，无功能段=回炉**
- 每段"钩子内容"必须写出具体的"继续看的理由"，禁写"留悬念"这类空话
- **节奏段可跨多个分镜，一个分镜也可被多个节奏段覆盖**——它是检查单位，不约束拍片
- 但**「对应子分镜」列必须与分镜提示词块里的时间段一一对上**，且各镜 Σ子分镜 = 该镜整秒时长
- 原文不足一整套序列时，**排到第 N 段就收，不补齐**，第 N 段末仍须带钩子
- 核对四项：每段有功能□ 段段有钩子□ 末段落钩子点□ 未为凑段增删内容□
