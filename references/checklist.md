# 检查单（执行时逐项打钩，答不出=按默认淘汰，禁止"再想想"）

> 卡序与 SKILL「S0a→S6」对应：卡六=前置建卡/拆点，卡一~卡五=S1~S5，卡七=节奏配段（S3.5/S6），卡八=S6 总检。
> **判"要不要返工"以卡八 13 项为准**；SKILL「质量红线·必达」为其红线段摘要，二者冲突时以卡八为准。

> ⚠️ **本单「段」字有三种含义，读前先分清**（SKILL 核心定义与留人节奏模型有完整辨析）：
>
> | 写法 | 指什么 | 出现场景 |
> |---|---|---|
> | **子分镜** | 分镜内的时间分段 = 提示词里的「时间段」，Σ = 分镜时长 | 起幅声明、景别切换、声轨、微表情**逐子分镜**过 |
> | **节奏段** | 节奏模型的检查组，约 10s，可跨分镜 | 功能标签、段尾钩子、集尾落点**逐节奏段**过 |
> | **段**（泛称） | 上下文自明时使用，如「段首」「首段」 | 段首挂牌、首段声明 |
>
> **本单凡写"功能标签、段尾钩子、每段有功能"的，一律指节奏段；凡写"起幅、景别切换、声轨、微表情"的，一律指子分镜。**

## 一、内容点准入三问卡（S1，逐点过）

- [ ] ①拍它有什么意义？功能=________（剧情推进/节拍功能/情绪曲线/上下文衔接/因果逻辑/伏笔/反转/高燃/技术必需）
- [ ] ②观众买不买单？（情绪价值/信息价值/爽点，一句话说清）
- [ ] ③命中刚需菜单哪类？（全不命中=平平无奇=**不拍**）

**台词点附加**：答不出台词四问=**删**（交 S2）。

**权重裁决**（过准入≠同权）：高能点（爽点/燃点/爆发/反转/反击/高潮铺垫）→多拍，给足时长+特写+反应位；过渡点→少拍，压秒能并则并；禁连续两个无功能子分镜（平铺直叙=节奏事故）。

**集尾钩子**：本集最后一镜是否落在钩子点（悬念/反转/情绪顶点）？否则→从后往前找最近张力顶点重结。

## 二、台词四问卡（S2，逐句过，含内心独白）

- [ ] ①意义？（推动剧情/上下文衔接/揭露"为什么"/情绪外化/节拍引信；无一命中→删）
- [ ] ②可压缩？压缩版=________；三保检验：意思一致□作用一致□衔接不断□；节省<0.5s 且伤语气→**不压缩**并记录
- [ ] ③**删了上下文断不断？** 断→必留；不断且四问①无命中→删
- [ ] ④**能否用动作代替？** 不可见信息→不能代替；可代替→改动作、删台词
- [ ] 定稿五件套齐全：文本+语气标签+可视化三件套+占位时长+OS标记（如·VO）
- [ ] OS专项：第一视角第一时间□画面内载体□（OS·VO）标注□落点指明□；是第三视角→旁白，不录入
- [ ] 声画对位：①留下来有用且观众买单□ ②删它有影响/衔接断□ ③压缩后三保不丢原意□ ④与当下画面应景□（不应景=白搭→调台词位置/调画面/删）

## 三、反推自检卡（S3）

- [ ] 同一画面关系已合并；不同画面关系已拆分
- [ ] 单镜子分镜1-4个
- [ ] 时长算法正确：顺序节拍累加，节拍内并行点取**max**（自查：有没有把同步点累加了？）
- [ ] 总时长≤12s（含必要0.5s承接）→单镜；>12s→已按画面关系/节拍边界拆镜
- [ ] 撑不满10s→已合并/延展/回S1重组（三选一，按序尝试）
- [ ] 首镜未独占建镜段；空间关系在第二个主体入画时确立
- [ ] 反应裁决已做（信息量>情绪对比>预期管理），反应位置已定（最后一个子分镜/独立分镜）
- [ ] 镜级复核：每镜回炉过三问，答不出→合并或删除

**延展合规**（撑不满 10s 时逐条过，三条全中才算延展）：
- [ ] 该点独立过了 S1 三问（有功能标签，非为填时长新增）
- [ ] 延展后所属**节奏段**仍持有功能标签（炸弹/升级/加压/临界/爆发/钩子之一）
- [ ] 延展部分是"有动词的动作"或"有变化的表情"，非静态描写堆字
- [ ] 三条缺一→已判为凑数，回合并/回S1，未强写

**整秒收敛**（Σ子分镜 → 分镜时长，方向不可反，**以 12s 为界**）：
- [ ] **Σ子分镜时长已算出**（粒度 0.5s，未预先凑整）
- [ ] Σ子分镜 = 分镜时长（**判定权在卡八第 2 条**，此处只确认已算）
- [ ] **Σ≤12s 的镜：直接整镜交付**，未为凑 10s 或凑"整"而增删（10～12s 之间任意值合法）
- [ ] **Σ>12s 的镜：装到 12s 为止，余下内容按内容点（节拍/剧情/台词/情绪）自然顺延到下一镜**，未压缩内容硬塞
- [ ] 切点选在内容点的自然边界（动作做完/台词说完/情绪落定），非硬断
- [ ] Σ不足 10s 的镜：已合并/延展/回S1重组/并入下一镜承接块（四选一，保住不单出短镜）
- [ ] 无"先定整秒再删内容"的倒序操作
- [ ] 收敛中删掉的点已回 S1 记淘汰日志（未在 S3 偷抹）

## 四、连续性自检卡（S4）

- [ ] 除全片首镜、新场景首镜外，同场景相邻分镜都有0.5s承接块
- [ ] 承接块自包含：人物屏幕位置+朝向+姿态+镜头状态+落幅景别（空镜=环境锚点）
- [ ] 承接块与上一镜落幅完全对得上（站位/景别/镜头状态）
- [ ] 俯视图已画：屏幕映射声明□180°轴□机位节点□未入画人物标位□
- [ ] 轴线未越；越轴处有过渡分镜（空镜/关系中景/反应特写）且过渡后才翻转
- [ ] 多人场景：轴线按主要对峙双方划定

## 五、画面行质检卡（S5，逐子分镜过）

- [ ] 起幅景别：本镜**首个子分镜**已声明；相邻子分镜景别切换处已声明"X景别起幅，"；同景别连续的子分镜未乱声明
- [ ] 运镜答全四问：跟随谁/怎么移/移到哪/落定景别；无子分镜首挂牌；无无目的运镜
- [ ] 实时流：连接词明示时序；读任何一处都知道当下状态
- [ ] 台词：位置=真实时刻；语气标签+可视化三件套；说话人屏幕位置+视线落点都在
- [ ] 反应：每句台词后有受话方物理反应，或已记录"不需要"的理由
- [ ] 站位：入画声明位置+朝向；位移用屏幕相对方向
- [ ] 微表情：近景/特写已写AU转译的可见描述
- [ ] 质感基线（I1）：风格行构图定位□光影行光源+色温+体积光+物料清单□
- [ ] 物理真实（I2）：布料受力/重量感/惯性/粒子随光源
- [ ] 禁僵硬：至少一处持续微动
- [ ] 音效行：具体声源；人声+动作声+环境声；无BGM；无抽象/音乐性描述
- [ ] 字幕：无（每个时间段独立成行）

## 六、建卡与拆点自检卡（S0a/S0b，逐章过）

**建卡（S0a）**：
- [ ] 角色卡四要素齐：姓名+年龄｜外观锚定（=参考行全文）｜声线特征｜人物关系
- [ ] 场景卡五要素齐：地点+时段｜光影基线｜物料清单｜空间结构（门/窗/柱/可站位区）｜环境锚点编号（E1…）
- [ ] 外观变更已过准入：变更本身有剧情意义才生成新版本（如"萧远·染血版"）
- [ ] 旧版本已标"不再复用"
- [ ] 状态存档已产出：角色卡 / 场景卡 / 站位表 / 轴线（跨章续做靠它）

**拆点（S0b）**：
- [ ] 每点 = 类型标签 + 一句话内容 + **原文锚点**（无锚点=不可回溯，退回重拆）
- [ ] 动作描写分流正确：改局势→剧情点｜外化情绪→情绪点（未设"动作点"第五类）
- [ ] 环境描写已旁路到场景卡；烘托情绪的另补一条情绪点
- [ ] 心理活动已给可视化转译（微表情/动作/视线落点）；转译不了的已标弃用
- [ ] 回忆/闪回**未预设弃用**，保留待 S1 裁定
- [ ] 独白候选已分辨：第一视角第一时间→留 S2｜第三视角讲述→标旁白，不录入
- [ ] 跨场景处已插 `──切场──` 标记

## 七、节奏检查卡（每集交付前·S3.5/S6，逐**节奏段**过）

- [ ] 节奏段划分依据是**原文内容点**（节拍/剧情/台词），不是时长配额
- [ ] 总时长=各节奏段累加所得，未为使总时长好看而增删内容
- [ ] 0-1秒有炸弹：冲突顶点前置/反常识画面/悬念特写/动作爆点（四选一），无淡入无开场白
- [ ] 10秒内三锁定：看谁（外观）/在干嘛（动作）/图什么（目标或悬念）
- [ ] 每个节奏段有功能标签（炸弹/升级/加压/临界/爆发/钩子），无"无功能节奏段"
- [ ] 每个节奏段段尾有"继续看的理由"，段段有钩子
- [ ] 高能节奏段时长给足+特写+反应位；过渡节奏段已压秒；无连续两个无功能子分镜（禁平铺直叙）
- [ ] 无空转子分镜（信息密度为零的已删或并）
- [ ] 集尾落在钩子点（悬念/反转/情绪顶点）
- [ ] 本集核心人物外观在参考行锁定，全程观众知道主体是谁/在干嘛/图什么
- [ ] 不足整套序列时：按前 N 个节奏段收，未补齐、未拉长（第 N 段末仍带钩子）

## 八、交付前13项总检（S6，逐镜过）

> **本卡是返工判定的唯一依据。**

1. [ ] 每镜时长=10/11/12整秒
2. [ ] Σ子分镜时长=分镜时长
3. [ ] 承接近包含且与上镜落幅一致（首镜/新场景除外）
4. [ ] 起幅声明规则执行正确
5. [ ] 运镜四问全答
6. [ ] 台词位置=真实时刻+语气可视化+视线落点+屏幕位置
7. [ ] 反应在位（或有不需反应的有效记录）
8. [ ] 并行点取max，无同步点累加错误
9. [ ] 动作链起点→过程→终点；禁词零出现（突然/骤然/猛然/心理动词/画面行情绪命名/否定式/空泛炫技/悬空引用/旁白）
10. [ ] 微表情（近景特写必写）+持续微动
11. [ ] 音效无BGM；字幕：无
12. [ ] 轴线一致（俯视图核对通过）
13. [ ] 头部三行完整：风格构图定位/光影物料/参考行锚定
